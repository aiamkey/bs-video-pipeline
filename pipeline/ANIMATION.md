# 动画与转场 · 方法说明

> **分工**：这份文件只定义"看起来应该是什么样、什么时候用、参数多少"。
> **具体实现交给执行方**——本工程的 `Cards.tsx`、`video-shotcraft` 的镜头卡、或剪映手工，都行。
> 换执行方不影响这份说明书；换说明书才需要重做。

---

## 0. 一条判断标准

**好的动画不让人注意到动画本身，只让人注意到信息。**

出现三个症状说明过了：观众能数出"飞入、回弹、旋转"；一句话里画面动两次以上；转场比内容还花。

---

## 1. 六个入场动作

按"信息需要被怎么读"选，不按好看选。

### A1 淡入上移（默认）

- **视感**：元素从下方 20–24px 处浮上来，同时从 15% 透明到 100%，用时 0.35–0.45s，末段减速。
- **用在哪**：90% 的文字卡。它是"默认值"，不加分也不出错。
- **参数**：`card.enter_ms`、`card.opacity_start`
- **执行**：`Cards.tsx` 的 `Reveal`（已实现）／shotcraft `element-body-moves`

### A2 硬切换姿势

- **视感**：没有过渡。上一帧角色叉腰，下一帧角色抬手指，中间不插任何补间。
- **用在哪**：卡通角色演情景剧。凯哥原片角色没有骨骼和口型，靠"换一张静态图"表达情绪。
- **参数**：切换点对齐语音重音，误差 < 2 帧
- **执行**：`Sequence` 边界（已实现）／shotcraft `beat-cut-moves`

### A3 左/右滑入

- **视感**：从画外 60–80px 处滑到位置，0.3–0.4s，带轻微减速；方向跟随阅读方向（新内容从右进，回退从左进）。
- **用在哪**：并列项依次进场、章节之间换页。
- **参数**：位移 60–80px；多条时 stagger `card.stagger_ms`
- **执行**：`DataFilm` 的 `Enter kind="slideL|slideR"`（已实现）／shotcraft `blur-slide`、`deck-deal-flyin`

### A4 中心缩放回弹

- **视感**：从 94% 放大到 100%，前 60% 时间走完 90% 的距离，最后一点"顿"住。**不要过冲**（不要 105% 再回落，那是 PPT 味）。
- **用在哪**：独立数字、单个结论词、需要"落下来"的一句话。
- **参数**：`0.94 → 1.00`，200–260ms
- **执行**：`Enter kind="zoom"`（已实现）／shotcraft `impact-feedback`

### A5 逐行淡入

- **视感**：条目一行一行出现，间隔 80–120ms，已出现的不动。
- **用在哪**：三条以上的清单。**替代"整块刷出来"**——逐行让观众跟着念。
- **参数**：`card.stagger_ms`；行数 > 4 时压缩间隔到 70ms
- **执行**：`TriList` / `BoardCard`（已实现）／shotcraft `list-reveal`、`beat-step-list-theme-cycle`

### A6 遮罩揭示 / 数字滚动

- **视感**：文字从一条细缝里"长"出来（遮罩上移）；或数字从 0 滚到目标值，滚动 0.5–0.8s 后停。
- **用在哪**：全片只用 1–2 次，用在最想让人记住的那一个数字或那一句。
- **参数**：数字滚动时长 0.5–0.8s，末尾停顿 ≥ 0.4s
- **执行**：shotcraft `draw-svg-trace`、`circle-match-iris`、`countdown-arc-scatter`；本工程 `aifl/DigitRoll.tsx`（未接入 DataFilm）

## 2. 转场（镜头之间）

凯哥原片 30 秒 7 次切换，**全部硬切**，只有章节开头有一次淡入。所以默认值只有一个：

| 代号 | 视感 | 什么时候用 | 占比 |
|---|---|---|---|
| `cut` | 直接换，无过渡 | **默认**。同一段落内的所有切换 | 85% |
| `fade` | 4–6 帧交叉淡化 | 章节之间、时间跳转 | 10% |
| `slideL` / `slideR` | 新画面从侧面推入 | 并列对比、流程推进 | 4% |
| `zoom` | 轻微推近 94→100 | 强调"这一句很重要" | 1% |
| `slam` | 从 116% 砸到 100% | 打脸句、错误示范 | ≤1 次/条 |

**禁令**：不加旋转、模糊、粒子、光效、3D 翻转。这些在知识口播里只增加"廉价感"。

参数写法（每句可单独指定，不写就是 `fade`）：

```json
"card": { "type": "copy", "text": "…", "transition": "cut" }
```

## 3. 五步循环：场景怎么排、怎么切

凯哥每条视频都是这个循环，一轮 60–90s，全片 6–7 轮：

```
① 讲师提问 ──cut──▶ ② 黑板编号 ──cut──▶ ③ 学员演错 ──fade──▶ ④ 局部图解 ──cut──▶ ⑤ 真人/动作 ──fade──▶ 回 ①
```

| 步 | 画面职责 | 用什么卡 | 停留 | 切换进 |
|---|---|---|---|---|
| ① 讲师提问 | 建立权威、抛出问题 | `teacher`（讲师剪影 + 一句问） | 2.5–3.5s | `fade` |
| ② 黑板编号 | 把答案拆成 1 2 3 | `board`（墨绿 + 白数字） | 3–4s（逐条出现） | `cut` |
| ③ 学员演错 | 制造羞耻、"这不就是我" | `wrong`（红叉 + 一句错法） | 2.5–3s | `cut` |
| ④ 局部图解 | 给证据、讲原理 | `annotate`（实拍 + 红点标注） | 3–4s | `fade` |
| ⑤ 真人/动作 | 给今天就能做的动作 | `image` / `copy`（动作句） | 2.5–3s | `cut` |

**为什么 ③→④ 用 fade**：这是"错误 → 原理"的认知跳跃，观众需要 0.2s 换气。
**为什么其他都 cut**：连续 cut 制造"信息密度"，fade 多了会拖。

## 4. 节奏硬指标

| 指标 | 值 | 为什么 |
|---|---|---|
| 单镜时长 | 2.5–3.0s（中位） | 低于 2s 看不完字幕，高于 4s 划走 |
| 单镜上限 | 4.0s | 超过就要拆句 |
| 连续静止 | ≤3.0s | 超过观众以为卡了；凯哥原片最多 5s 静止，靠字幕轮换撑 |
| 入场时长 | 350–500ms | 短了像闪，长了像慢动作 |
| 多条 stagger | 80–120ms | 再密就看不清 |
| 起点透明度 | **0.15** | 从 0 起会在切点闪白（本项目踩过的坑） |

## 6. 验收：怎么判断"像了"

抽 5 帧对照原片，问三个问题：

1. 切点是否落在语音的重音/句末？（不是"平均 2.8 秒切一次"）
2. 有没有一屏超过 3 个元素？
3. 连续静止有没有超过 3 秒？

三条都过，动画就是对的；有任一条不过，先改节奏，别加特效。

## 7. 卡通素材：当幻灯片放，不要当动画做

凯哥的卡通画面**不是动画，是图**。一张静态图停留一两秒，硬切到下一张，像翻 PPT。
省掉全部骨骼、口型、补间，只剩"图 + 切"两件事。

### 7.1 为什么这样反而好看

- 观众要的是"看到那个状态"，不是"看到它动"。塌着背刷手机，一张图就够。
- 静态图不抢注意力，语音和字幕才是主线。
- 一组图（3–4 张）连起来，观众自己脑补出"动作序列"，比真动画更省、更准。

### 7.2 参数

| 项 | 值 | 理由 |
|---|---|---|
| 每张停留 | 1.2–2.0s | 低于 1s 看不清，高于 2s 以为卡住 |
| 同一话题张数 | 2–4 张 | 少于 2 张没有"变化"，多于 4 张像相册 |
| 切换 | **硬切 `cut`** | 淡入淡出是 PPT 味；硬切更像"翻页" |
| 推近 | 每张 1.000 → 1.035 | 让画面不死；顺带把"静止占比"压到 0 |
| 构图 | 主体偏一侧（左或右 1/3），另一侧留白 | 留白处放大字 |
| 图上文字 | **不要** | AI 生成中文必乱；文字交给卡片层 |

### 7.3 角色一致性（关键）

同一个角色出现在多张图里，靠**同一段角色描述**锁死：

> 扁平矢量卡通插画，同一个留短黑发、穿白T恤和深灰长裤的亚洲男生，简洁粗黑描边，低饱和暖灰背景，画面右侧留白，无文字

只换结尾的动作句：`瘫在沙发上低头刷手机` / `站在镜子前拨弄乱发` / `低头含胸走路` / `侧身站直肩膀打开`。
**不要**每张重写风格词，否则脸会变。

### 7.4 生图：key 由使用者提供

工具：`tools\img.py`。**用哪家、用谁的 key，都在 `config.json` 的 `images` 段改，不改代码。**

```json
"images": {
  "provider": "openai",
  "model": "gpt-image-1",
  "size": "1536x1024",
  "base_url": "https://你的中转站/v1",
  "api_key_env": "OPENAI_API_KEY",
  "api_key": ""
}
```

三种规范任选：

| provider | 适用 | base_url | 说明 |
|---|---|---|---|
| `openai` | OpenAI 标准 `/v1/images/generations` | 官方留空；中转站填到 `/v1` 之前 | 兼容 one-api / new-api / ohmygpt 等所有中转 |
| `dashscope` | 阿里百炼 wanx | 留空 | 异步任务 + 轮询，默认值 |
| `ark` | 火山方舟 doubao-seedream | 留空 | `/api/v3/images/generations` |

key 的三种给法（优先级从高到低）：`--key` 参数 → `api_key_env` 指定的环境变量 → `images.api_key` 写死。

```powershell
# 换 key 只改环境变量
$env:OPENAI_API_KEY="sk-xxx"
python tools\img.py "提示词" out.jpg --provider openai --model gpt-image-1 --size 1536x1024

# 验证 key 读到了没
python tools\img.py --check
```

出图 1280×720（dashscope）或 1536×1024（gpt-image-1），20–60s/张。

**换 provider 会漂脸**（实测：同提示词换一次 seed，角色从"扁平黑发"变成"写实肤色"）。
锁脸三条，按代价从低到高：

1. `--seed 20261124` 固定随机种子（同一模型内有效，换模型无效）
2. 提示词里把角色的**六个特征全写死**：发型长度、发色、上衣颜色、裤子颜色、描边粗细、背景色
3. 用参考图（`Qwen/Qwen-Image-Edit` 或 seedream 的 image 参考）以首张图为准做后续帧
**卡通素材必须锁同一段角色描述**（见 7.3），换 provider 也要沿用同一段文字，否则脸会变。

### 7.5 dashscope 直连（旧写法，等价）

```powershell
$env:NO_PROXY="dashscope.aliyuncs.com"
python tools\ds_img.py "<角色描述>，<动作>" lbr-promo\public\textures\slides\s1.jpg
```

1280×720，出图约 20–40s/张。批量就循环四五个动作。

### 7.6 播放：`slides` 卡

```json
"card": {
  "type": "slides",
  "frames": ["textures/slides/s1.jpg", "textures/slides/s3.jpg"],
  "hold": 1.5,
  "text": "塌着背，低着头",
  "transition": "cut"
}
```

字段：`frames[]` 图序列 / `hold` 每张秒数 / `push` 是否微推（默认开）/ `fit` contain|cover / `paper` 是否铺纸白底 / `captions[]` 可选的逐张角标。

一句话配 2–4 张图，语音说完正好翻完。

### 7.7 什么时候不该用

- 讲原理（用 `annotate` 实拍标注更可信）
- 讲清单（用 `list` / `board`，图会稀释信息）
- 已经连续三条都是卡通 → 换真人图或大字卡，否则像动画片
