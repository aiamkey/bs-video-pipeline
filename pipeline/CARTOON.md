# 卡通素材规格（数量 · 节拍 · 衔接）

> 数据来源：`qa2\ref\v1-shuaishuai.mp4`（654s）与 `qa2\ref\v2-pengyouquan.mp4`（698.5s）
> 测量方法：`tools\shot_stats.py`（帧差切点）+ `tools\cartoon_ratio.py`（flat-color 判卡通）+ 60s 切片逐秒分类
> 样本：v1 取 200–260s、v2 取 30–90s，各 60 帧（1fps）

---

## 1. 他的卡通图到底有多少

| 指标 | v1 锐评变帅 | v2 朋友圈 | 结论 |
|---|---|---|---|
| 全片镜头数 | 477 | 411 | — |
| 镜头密度 | **44 镜/分钟** | 35 镜/分钟 | 平均每 1.4–1.7s 一个镜头 |
| 卡通画面占比（60s 样本） | **62%** | **58%** | 卡通是主画面，不是点缀 |
| 卡通段数（60s） | 7 段 | 6 段 | 约 **6–7 个卡通场景/分钟** |
| 每段停留 | 中位 **6.0s**（最长 8s） | 中位 **4.5s**（最长 11s） | 一个场景停 5–6 秒 |
| 相邻卡通帧"同场景"比例 | 37% | 48% | 一半以上的时间**场景没换，只换了姿势** |
| 全片静止帧占比 | 41% | 44% | 画面本身几乎不动，动的是"翻页" |

**换算到一条 2 分钟视频**：卡通约 70–75 秒 → 按每 1.5s 翻一页 ≈ **45–50 个画面**；
去重到场景 ≈ **12 个场景 × 每个 3–4 张姿势图 = 36–48 张素材**。

> 我们 EP02 只放了 3 张 —— 差了**一个数量级**。这就是"卡通图太少"的量化原因。

## 2. 为什么"切换得很自然"

不是因为转场花，恰恰相反：**他几乎不用转场，靠的是"同一个人、同一个房间、只换动作"**。

60 秒样本里，卡通段内部平均每 1.3s 换一次画面，但背景、机位、人物造型全程不变；观众读到的不是"换镜头"，而是"他在动"。

### 衔接六法（按重要性排序）

**法 1 · 同场景换姿势（占比最高）**
同一个背景、同一机位，只有人物动作变：坐着 → 抬头 → 低头。
实现上就是两张同尺寸图硬切，不需要任何过渡。

**法 2 · 机位三件套：中景 / 侧面 / 局部**
- 中景（腰以上）讲状态："他瘫在沙发上"
- 侧面（全身）讲体态："他走路塌着背"
- 局部（手 / 手机屏 / 眼睛）讲细节："她已读不回"
三件套轮着来，画面就不会"一直一个框"。

**法 3 · 视线与动作方向连续**
上一张人物看向右边，下一张如果要接"她在对面"，就让人物仍朝右、把对方放在右侧。
方向断了，观众会觉得"跳"。

**法 4 · 一张图里只改一个变量**
换表情不换姿势，换姿势不换背景。一次改两样，就变成"另一个场景"，衔接感消失。

**法 5 · 文字跟着图走，不跟镜头走**
同一场景里，字幕/标签可以换三次，但底图不动。凯哥大量使用这个：图定住，字在变。

**法 6 · 段与段之间才用淡入（0.2s）**
场景切换用极短交叉淡化；场景内部一律硬切。整条片子 fade 不超过 5 次。

## 3. 生成规格（复刻配方）

### 3.1 统一提示词骨架

```
扁平矢量卡通插画，同一个留短黑发、穿白T恤和深灰长裤的亚洲男生，
<机位：中景 / 侧面全身 / 局部特写>，
<动作：…>，
简洁粗黑描边，低饱和暖色调，画面右侧留白，无文字
```

- **必须每张都重复"同一个…"这句**，模型靠它维持角色一致
- **右侧留白**是给大字卡/字幕让位，也是他能把文字压在画上的原因
- **无文字**必须写，否则模型会自己加英文标签

## 4. 在 `film.json` 里怎么排

一个场景 = 一个 `slides` 卡，卡内放同场景的多张图，`hold` 按句子长度给：

```json
{ "text": "她一不回消息，你就开始想是不是说错了。",
  "card": { "type": "slides",
            "frames": ["textures/slides/u1.jpg", "textures/slides/u2.jpg"],
            "hold": 1.5, "text": "她没回，你先慌了", "transition": "cut" } }
```

排布三原则：

1. **同一场景连用 2–3 个句子**，中间不换场景（观众才认得出"这是同一个他"）
2. 场景切换点对齐**语义转折**（讲完"状态"进"原因"），并且用 `fade`
3. 一条片子里卡通段合计占 **50%–60%** 时长；其余给文字卡与黑板

## 5. 验收：像不像

抽 6 帧，问三个问题：

1. 六帧里有几张是同一个人？（应该 ≥5）
2. 同场景内的两张图，除了动作还有别的地方变了吗？（应该没有）
3. 场景切换处，观众会不会觉得"画面跳了一下"？（应该不会，因为用了 0.2s fade）

三条都过，衔接就是对的。
