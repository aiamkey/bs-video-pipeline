# 成本与时间

> 对标 capcut-mate 的透明价格表：**每条片子花多少钱、花多少时间，先算清再决定要不要做**。
> 数字是 2026-11 的百炼/本地实测口径；涨价或换 provider 请改这里。

## 一、一条 2 分钟片（EP02 实测：117s / 630 字 / 12 图 / 41 轨段）

| 环节 | 用量 | 单价 | 小计 |
|---|---|---|---|
| 配音 | 630 字（cosyvoice-v2 `longcheng_v2`） | 约 1.8 元/万字符 | **≈ 0.11 元** |
| 逐字对齐 | 本地 whisper small（CPU） | 0 | **0** |
| 生图 | 12 张底板（`wanx2.1-t2i-turbo`） | 约 0.14 元/张 | **≈ 1.68 元** |
| 渲染 | 3094 帧 1280×720（本地 Remotion） | 0 | **0** |
| 混音 | ffmpeg loudnorm | 0 | **0** |
| 剪映工程 | 本地生成 + 加密登记 | 0 | **0** |
| **合计** | | | **≈ 1.8 元 / 条** |

改稿重跑：只改文案 → 配音 0.11 元；只改元素位置 → 0 元（不重新配音、不重生图）。
**所以"改文案成本 ≈ 一毛钱"**，不要因为怕花钱而不敢改稿。

## 二、可选付费能力（按需，默认不开）

| 能力 | 单价 | 什么时候值得买 | 我们的判断 |
|---|---|---|---|
| 云端 ASR（autosubrt） | **0.00022 元/秒**（10 分钟片 0.13 元） | 片子 > 5 分钟，或本地 whisper 断句错 | 值得。比本地省心，几乎免费 |
| 声音复刻（cosyvoice-v3.5-plus） | **9.9 元/个** + 1.5 元/万字符 | 要求"就是本人的声音" | **暂不接**：现有 `longcheng_v2` 已够（F0 156Hz / 动态 8.5dB，目标 163/7.1） |
| 文生图（更高阶模型） | 0.3–0.5 元/张 | 需要同角色多姿势 / 对手戏 | 等到真要"演情景剧"时再说 |
| 文生视频（seedance 480P） | **0.45 元/秒** | 需要镜头运动 | 2 分钟片 = 54 元，性价比太低 |
| 数字人（图片说话） | 0.5 元/秒 | 想替代真人出镜 | 2 分钟片 = 60 元；等确定性收入再说 |
| 音乐生成 | 0.25 元/次 | 需要 BGM | 不需要：**凯哥原片实测无 BGM** |
| 对象存储上传 | 0.005 元/MB | 云端成片 | 不需要，本地全链路 |

## 三、时间预算（单条，熟手口径）

| 环节 | 耗时 | 卡住时的症状 |
|---|---|---|
| 选题 + 写稿 + 分屏标注 | 20–40 min | 写不出 38 句 → 先列 11–14 个"这句话在什么场景" |
| `plan` 估时长 | 5 s | 字数差太多 → 调 `voice.rate` 或删句 |
| 配音（按章 7 次） | 2–3 min | 报 key 错 → 见 TROUBLES §5 |
| 对齐（whisper） | 1–3 min | 卡住 → `HF_ENDPOINT` 没设 |
| 生图 12 张 | 4–6 min | 脸不一致 → 加 `--seed` + 人物特征写死 |
| `audit.py` | < 1 s | FAIL → 按提示挪元素，不用渲染 |
| 渲染 3094 帧 | 80–100 s | 权限错 → TEMP 没指到 `.tmp-remotion` |
| 混音 + `check.py` | 20 s | 响度不对 → 看的是 raw 不是 final |
| 剪映工程生成 + 加密登记 | 6 s | 版本弹窗 → 看 `jy_versions.json` |
| 剪映里手工微调 | 5–15 min | — |
| **合计** | **约 1.5–2 小时** | |
