# 凯哥式短视频 · 规格书

> 本文件是**规则**，不是参数表。所有数字以 `config.json` 为准，这里只写字段名。
> 改数值去 `config.json`，不要改本文；本文只在规则本身变化时更新。

---

## 0. 一条总原则

**文案决定卡型，卡型决定素材，素材决定动效。顺序不能反。**

先想这句话要观众"相信什么"，再选能证明它的画面，最后才想怎么让它动起来。
反过来（先找好看素材再硬凑文案）就会得到一条漂亮但没人看完的片子。

---

## 1. 内容方法论

### 1.1 本质

**替男生把不敢说的判断说出来。**
不是教技巧，是替观众完成一次"终于有人说了"的情绪释放。技巧只是释放之后的落点。

### 1.2 价值三层（缺一层就留不住人）

| 层 | 作用 | 例 |
|---|---|---|
| 情绪价值 | 3 秒内让他觉得"说的是我" | "你不是丑，你只是没打理" |
| 认知价值 | 给一个他没听过的解释 | "含胸驼背偷走 3 厘米身高" |
| 工具价值 | 给一个今天就能做的动作 | "每天靠墙站 5 分钟" |

只给情绪 = 爽完就划走；只给工具 = 像说明书。

### 1.3 选题

**三问**（三问全过才做）：
1. 这句判断，男生心里是不是早就有了、只是没人替他说？
2. 我能不能给一个"为什么"（机制），而不只是"怎么做"？
3. 看完他今天能不能做出一个动作？

**四母题**：外貌 / 聊天 / 择偶 / 自我认知。变帅类只做第一个，但每期都要挂到"择偶"上收口——否则没有行动理由。

### 1.4 开场（前 3 秒只干一件事：自我指认）

不介绍自己、不预告干货、不寒暄。**第一句必须让目标观众在心里点头**。

可用：断言（"你长得不丑"）/ 否定（"不是脸的问题"）/ 点名（"1 米 7 以下的兄弟"）/ 立规矩（"记住三条"）/ 代价（"这条能省你三年"）。
不可用：自我介绍、"今天给大家分享"、"话不多说"。

### 1.5 结构

**承诺 → 兑现 → 加码**。

- 承诺：开头给出"看完你能得到什么"，且必须具体到可验收（"照做一个月，有人夸你变精神"）
- 兑现：中段一条一条给，每条都走"现象 → 原理 → 动作"
- 加码：结尾给一个超出预期的判断（"变帅从来不是脸的问题，是你愿不愿意开始"），把工具片抬成价值观片

### 1.6 可信度五装置

数字（具体到不合理：3 厘米 / 21 天 / 165→175）、机制（进化心理学 / 肌肉记忆）、案例（明星 / 身边人）、对比（前后 / 左右）、亲历（"我自己试过"）。
**一条片至少用 3 种**，全用同一种会显得在编。

### 1.7 人格

**敢说 ＞ 说对**。凯哥的护城河不是知识准确，是敢下判断、敢得罪人（"泡妞高手都是丑的"）。
但每条判断后面必须跟一个能落地的动作，否则就是纯情绪。

### 1.8 画面即证据

每个论点配一个"看得见的东西"：不是配图，是**证据**。说下颌线就上下颌线特写，说含胸就上侧面对比，说颜色就上四色卡。
没有证据的句子，砍掉或合并。

### 1.9 复用三不变

人格（自称 + 称"兄弟们"）、结构（承诺-兑现-加码）、评级体系（给到拉 / 给到顶级 / 给到夯）。
**这三样每期都一样，观众才认得出是你。**

### 1.10 不可迁移项

他的脸、他的失败史、他的地域身份、他已有的 63 万粉信任。不要模仿这些，模仿了也不像。

### 1.11 迁移检查表

- [ ] 第一句是判断，不是介绍
- [ ] 三层价值都有
- [ ] 至少 3 个可信度装置
- [ ] 至少 3 个可执行动作
- [ ] 结尾抬到价值观，不是总结
- [ ] 全片有一个"敢说得罪人"的句子

## 2. 文稿规格

参数见 `config.json → text`。

### 2.1 句子

- 单句 `text.sentence_min_chars`–`sentence_max` 字（8–18）。超过就拆。
- 逗号 : 句号 ≈ `text.comma_period_ratio`（3 : 1）：口语是逗号串起来的，不是句号切开的。
- 落点必须是**实词**。"所以我们要重视这件事"——落点是"事"，虚的，删。
- 数字用阿拉伯数字（3 厘米 / 21 天），读起来更有冲击。

### 2.2 开场八式

断言 / 否定 / 点名 / 反问 / 立规矩 / 预告价值 / 打脸 / 代价。
选一个，不要叠加。

### 2.3 中段四拍（每条都用）

**现象**（你是不是…）→ **原理**（因为…）→ **动作**（今天开始…）→ **金句**（一句能截图的）。

### 2.4 金句五公式

- A 比 B 更 C（"干净比帅更耐看"）
- 不是 A，是 B（"不是套路，是你得有自己的事"）
- X 偷走 Y（"含胸驼背偷走 3 厘米"）
- 你只需要 N 件事（"这五件事，没有一件需要天赋"）
- 时间 + 变化（"一个月，走路都不一样"）

### 2.5 数字包装四招

具体到不合理 / 减法制造损失（少 3 厘米）/ 周期制造希望（21 天）/ 比例制造稀缺（98% 不知道）。

### 2.6 人称密度

"兄弟们" `text.bro_per_100_chars`（每 100 字 0.4 次）；"你" 每 2 句 1 次（`text.you_per_sentence`）；"我们"少用（拉远距离）。

### 2.7 标点与停顿

逗号 0.15–0.25s，句号 0.3–0.5s，不用破折号；全片问号 `text.question_total` 个（3–5），多了像审问。

### 2.8 禁忌六条

广告腔（"让我们一起"）/ 三连排比 / 抽象名词 / 超 25 字长句 / 结尾总结陈词 / 自问自答超过 2 次。
清单见 `config.json → text.banned`。

## 3. 动画规格

> **本节只定义视感与参数；具体怎么实现交给执行方**（本工程 Cards.tsx / ideo-shotcraft 镜头卡 / 剪映手工）。
> 六个入场动作的完整描述、shotcraft 卡名映射、五步循环场景序列、验收方法 → [ANIMATION.md](ANIMATION.md)。

参数见 `config.json → video` 与 `card`。

### 3.0 时长

两种模式（`video.duration.mode`）：

- **auto**：不设目标，时长 = 稿子自然长度。适合内容优先、不迁就平台时长。
- **target**：`target_sec ± tolerance_pct` 卡死。反推：`需要字数 ≈ target × 语速中值`。

调节优先级：**先删字，再调语速**——语速超过 5.5 字/秒会开始"赶"。

### 3.1 节奏

- 单镜 `video.shot_median_sec`（2.5–3.0s），最长 `video.shot_max_sec`（4.0s）
- 30 秒切 6–8 次
- 连续静止 ≤ `video.still_max_sec`（3.0s）——超过观众会以为卡了

### 3.2 入场

- 时长 `card.enter_ms`（0.35–0.5s）
- 位移 40–120px（大了像 PPT 飞入）
- 多说一句的卡片 stagger `card.stagger_ms`（80–120ms）
- **起始 opacity 必须 `card.opacity_start`（0.15），不能是 0**——从 0 起会在切点闪白，这是实测踩过的坑
- 字幕淡入 4–6 帧

### 3.3 入场六式

淡入上移 / 左右滑入 / 中心缩放（0.94→1）/ 逐行淡入 / 遮罩揭示 / 数字滚动。

### 3.4 字幕

字号 `video.subtitle.size`（34–40px），距底 `video.subtitle.bottom_offset`（90–110px），黑边 + 投影，**一句一行硬替换**（不做滚动字幕）。
字幕内容 = 配音原文，一字不改。

### 3.5 进度条

`video.progress.segments`（4–7 段），段内填充式（`width: p*100%`）+ 前沿 3px 红块 + 底部全局 3px 红线。
段落名来自文稿 `chapters[].label`。

### 3.6 转场

**全硬切**。不加转场特效——凯哥原片 30 秒 7 次切换，全是硬切。
慢镜（静止 3 秒以上）靠字幕轮换 + 口播密度支撑，不靠画面动。

## 4. 素材规格

### 4.1 七类素材与占屏比

| 类型 | 职能 | 占屏 |
|---|---|---|
| 讲师/主讲 | 权威 | 55–65% 屏高 |
| 黑板/结构卡 | 列条目 | 满屏（底色 `card.green`） |
| 错误示范 | 制造羞耻 | 满屏 |
| 真人局部 | 证据 | 40–70% |
| 解剖线稿 | 讲原理 | 画面一侧 |
| 截图（微信/朋友圈/长文） | 真实感 | 30–45% |
| 大字卡 | 金句/过渡 | 满屏，字占 45–60% |

### 4.2 对比图五规则

左右各 50% / 同机位同焦段 / 左侧降饱和 30% / 只标一个词 / 中间留 8–12px 缝隙。

### 4.3 大字卡七规则

每行 ≤ `card.line_max_chars`（9 字）、≤ `card.max_lines`（2 行）/ 主字 `card.title_size` 或 `copy_size` / 只标红 `card.red_max_words`（1–2 处）/ 上下留白 15% / 不用渐变和纹理 / **一屏 ≤ `card.elem_max_per_card`（3 个元素）**。

### 4.4 配色

底 `card.bg`（#F6F4EF 纸白）/ 纸 `card.paper`（#FFFDF8）/ 墨 `card.ink`（#111）/ 灰 `card.muted`（#6B6B6B）/ 红 `card.accent`（#C8342B）/ 墨绿 `card.green`（#1B4A3C）。
**全片只用这六个颜色**，多一个就花。

## 5. 生产流程（8 步，全部对应 `run.py` 阶段）

| # | 步骤 | 产出 | 命令 |
|---|---|---|---|
| 1 | 选题+三问 | 一句话判断 | — |
| 2 | 写文稿 | `scripts/script-epNN.json` | — |
| 3 | 分句判卡型 | 每句一个 `card` | — |
| 4 | 配音 | `public/audio/{ep}.wav` | `run.py voice` |
| 5 | 对齐 | `src/data/{ep}-timeline.json` | `run.py align` |
| 6 | 生成 film | `src/data/film.json` | `run.py build` |
| 7 | 渲染+混音 | `out/{ep}-final.mp4` | `run.py render` → `mix` |
| 8 | 质检 | 报表 | `run.py check` |

第 2 步写完后先跑 `run.py plan`：按 5.25 字/秒估算每章时长，提前暴露"这条会做到 4 分钟"。

一条命令跑完：`run.py all ep01`。

### 5.1 第 2 步细则

先写"这个人现在最难受的是什么"，再写"他听完会做什么"。两句之间才是正文。

### 5.2 第 3 步细则（最容易糊弄、也最决定成片）

按顺序判：
1. 这句是**判断**还是**描述**？判断 → `copy`
2. 是**条目**还是**流程**？条目 → `list` / `no-list`
3. 有**数字**吗？有 → `stat`
4. 有**具体部位/动作**吗？有 → `brow` / `posture` / `image`
5. 是**章节开头**吗？是 → `section`
6. 上面都不占 → `copy`（默认，最安全）

**禁止连续 3 张同类型卡。** 连续同型 = 观众视觉疲劳。

## 6. 质检

`check.py` 输出两类：

- **硬指标**（FAIL 阻断）：文件大小 / 成片时长 / 总字数 / 整体字秒 / 语速异常句 / 响度 / 真峰值
- **风格指标**（WARN 提示）：单镜中位 / 最长单镜 / 最长静止段 / 静止占比

阈值全部在 `config.json → check` / `video`。
**风格指标不达标，改文案，不要改阈值。**

EP01 基线（可对照）：103.2s / 525 字 / 5.09 字秒 / −16.16 LUFS / 单镜中位 2.46s / 最长 4.76s / 静止 49%。

---

## 7. 改版规则

1. 改文案 → 从 `voice` 重跑（配音变了，时间轴必然变）
2. 改卡型/配色 → 从 `build` 重跑（film.json 变了）
3. 改 `config.card` / `config.video` → 从 `render` 重跑
4. 改 `config.voice` → 从 `voice` 重跑
5. **任何一次重跑后都要 `check`**，否则不知道有没有退化

版本号规则：`out/{ep}-final.mp4` 是交付版；试验版命名 `out/{ep}-vN.mp4`，不要覆盖。
